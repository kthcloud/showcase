# Running Pypsa on CBH cloud

This is a simple script based to demonstrate the use of the PyPSA: Python for Power System Analysis to be run under docker.

The code is based on the basic code provided on their site found at [https://github.com/PyPSA/PyPSA](https://github.com/PyPSA/PyPSA).

This project was created to demonstrate running the tool in CBH Cloud.
